# Prioritized tasks and acceptance criteria

Status legend: `[x]` complete, `[ ]` incomplete. P0 is required for the master-brief MVP; P1 begins only after the P0 acceptance gate. Task IDs remain stable across handoffs.

## Completed foundation

- [x] **P0.01 Shared coordination.** `AGENTS.md`, Claude entrypoint, requirements, implementation plan, architecture, decisions, tasks, status, and handoff log exist in the repository.
- [x] **P0.02 Modern application foundation.** Next.js App Router, strict TypeScript, React Flow, R3F/Three.js, Zod, IndexedDB adapter, Vitest, lint, and production build are configured.
- [x] **P0.03 Baseline real geometry.** Normalized prompts deterministically produce non-empty procedural geometry with floors, proportion, twist, terrace, courtyard, and material cues.
- [x] **P0.04 Baseline canvas.** Movable connected nodes, dotted infinite canvas, zoom, pan, fit-view, minimap, selection, and responsive shell work.
- [x] **P0.05 Baseline viewer/export.** Real geometry supports orbit, pan, zoom, reset, studio-like lighting, PNG capture path, and binary GLB serialization.
- [x] **P0.06 Baseline local persistence.** IndexedDB adapter saves and reopens project graph content; three starting presets load without credentials.
- [x] **P0.07 Safe provider boundary.** Meshy credential stays server-side; create request uses documented v2 endpoint; configured and live-verified states remain distinct.
- [x] **P0.08 Baseline verification.** Six unit tests, lint, production build, dependency audit, and manual browser smoke test pass.

## P0 — MVP gap closure, in execution order

- [x] **P0.09 Canonical domain contracts and migration.** Add runtime-validated `BuildingSpec`, `Artifact`, `GenerationJob`, typed `DesignNode`/ports, and `DesignRevision`; migrate persisted schema v1 without data loss. Acceptance: invalid specifications/connections fail clearly, jobs and artifacts are separate, and cycle rules are tested. *Done at the domain/storage layer (`contracts.ts`, `graph.ts`, `migrate.ts`); the UI still renders the v1 projection until P0.12/P0.13.*
- [x] **P0.10 Architectural geometry engine.** Support rectangle/circle footprints, podium/tower and multiple volumes, floor height, offsets, rotation, taper, stepped setbacks, facade style/glazing, roof, and materials. Acceptance: Terraced Tower, Twin Towers, and Cylindrical/Rotated Tower are structurally distinct and parameter changes are visible. *Done: pure `geometry.ts` layout + `typologies.ts` prompt→`BuildingSpec`; typologies terraced, twin, cylindrical, rotated, low-rise. Parameter edits via prompt/refinement only until P0.13; vertical/grid facade styles render as ribbon glazing; courtyard voids are not modeled.*
- [x] **P0.11 Project dashboard and CRUD.** Add new/open/rename/delete/sample flows and an empty-canvas first run with example prompts. Acceptance: project deletion is recoverable or confirmed, and every action persists correctly. *Done: dashboard with first-run example briefs, new/open/rename/delete (inline confirmation) and sample-as-copy; delete uses tombstones so legacy-key projects stay deleted. Not recoverable after confirmation.*
- [x] **P0.12 Typed executable canvas.** Add prompt, generation, model, render, and variation nodes; contextual add toolbar/menu; typed ports; supported-connection validation; and persisted viewport. Acceptance: connectors represent actual artifact flow and unsupported/cyclic wiring is rejected. *Done: UI runs on `SiftProjectV2`; `workflow.ts` evaluates the artifact flow (generation must be Run; downstream nodes are derived, stale when the prompt changes); typed handles, `isValidConnection`, add toolbar, per-node “Add next” menu, viewport persisted. Render node is wired but renders nothing until P0.16.*
- [x] **P0.13 Contextual inspector.** Add a collapsible selected-node panel for geometry, provider, material, camera, and render settings. Acceptance: irrelevant controls are absent and geometry changes create a new revision rather than overwrite the source. *Done: `inspector.tsx` (collapsible, per node type) + `spec-edit.ts`. Generation-node edits create a child artifact and `parameters` revision; variation-node edits are stored on the node and replayed. Camera/material-view/render controls are intentionally absent until P0.15/P0.16 rather than shown as dead inputs; materials (colour/kind) are editable.*
- [x] **P0.14 Non-destructive branching.** Create child nodes/specs/artifacts from parameter changes and follow-up prompts. Acceptance: two branches remain visible with correct lineage and restore after reload. *Done: “Branch” on Generation/Variation nodes adds a labelled sibling Variation+Model lane from the same source; variation recipes (follow-up text + parameter edits) are snapshotted into immutable artifacts with revisions to the shared parent on every save/blur/edit; the inspector lists versions and lets a Generation node switch back without deleting later versions.*
- [x] **P0.15 Expanded 3D viewer.** Add focus mode, automatic bounds framing, perspective/top/front/right/axonometric presets, frame/reset, grid/axes/shadow toggles, and clay/shaded/glass-concrete/wireframe modes. Acceptance: pointer gestures never drag/pan the outer canvas and controls are keyboard accessible. *Done: pure `viewer.ts` (bounds metrics, framing distance, presets) + rewritten `model-preview.tsx`: Focus (fixed overlay, Esc, focus return), Frame/Reset, perspective/axonometric/top/front/right (true orthographic), grid/axes/shadow toggles, shaded/clay/glass+concrete/wireframe. Keyboard: arrows orbit, +/− zoom, F frame; toolbar buttons use `aria-pressed`. GLB export always uses the shaded model.*
- [x] **P0.16 Render artifact pipeline.** Add render nodes bound to model, camera, material, light, background, and resolution. Acceptance: 1024×1024 and 1600×900 PNGs match the selected geometry/view; 1920×1080 is offered only when supported. *Done: Render nodes (settings: camera preset, material view, lighting, background incl. transparent, resolution) render offscreen via `render-image.ts`, store the PNG in a separate IndexedDB asset store (`storage.ts` `saveAsset/loadAsset/deleteAssets`), and record an immutable `render-png` artifact keyed to the exact model+settings (`renderInputKey`), so renders show “Needs render” when stale. Resolutions come from `supportedResolutions` (GPU limits + device memory); verified exact 1024×1024, 1600×900 and 1920×1080 output in Chromium.*
- [x] **P0.17 Complete persistence and assets.** Persist viewport, nodes, edges, prompts, specs, settings, revisions, artifacts, renders, and known provider jobs in IndexedDB without localStorage blobs. Acceptance: refresh/reopen restores the full Terraced Tower board and both branches. *Done: debounced autosave (900 ms) + flush on navigation/tab hide, save-status badge, viewer settings persisted in `settings.viewer` (optional, backward compatible), `projectSignature` change detection, save no longer rolls back concurrent edits; tests rebuild a full two-branch board with a render from IndexedDB after a simulated reload, and assert no localStorage/sessionStorage use. Only IndexedDB (`sift-projects`, `sift-assets`) is used. Known provider jobs persist in `jobs` (Meshy lifecycle is P0.18).*
- [x] **P0.18 Meshy async lifecycle.** Add protected paid-request confirmation, create/status/stream-or-poll/cancel where supported, normalized pending/running/completed/failed/timeout/rate-limit states, reload-safe jobs, GLB ingestion, and signed-URL expiry handling. - [x] **P0.19 Robust states and performance.** Add loading, empty, invalid geometry, persistence failure, provider failure, missing credential, unsupported WebGL, and recovery UI; add WebGL error boundary, mesh limits, throttling, and GPU cleanup verification. *Done: `limits.ts` triangle/mesh budgets enforced on edits and in the viewer (+ hosted-GLB cap); `ViewerBoundary`, WebGL-unsupported and context-lost fallbacks with restore; GLB download still works without WebGL; `frameloop="demand"` (0 idle frames) and dpr cap; viewer rebuilds only on content change; storage probe + banner, retry save, JSON backup/import; render panel and Meshy radio explain missing WebGL/credentials; `app/error.tsx`. - [x] **P0.20 Acceptance automation.** Add component and Playwright coverage for generate, inspect, edit, branch, render, GLB, persistence, missing credentials, provider lifecycle, and production regression. Acceptance: all ten scenarios in `PRODUCT_REQUIREMENTS.md` pass and key screenshots are retained. *Done: `e2e/acceptance.spec.ts` (10 tests, one per scenario, run against the production build; stable over 4 consecutive runs) + `e2e/helpers.ts`; jsdom component tests in `src/components/studio/components.test.tsx`; evidence in `docs/evidence/`.
